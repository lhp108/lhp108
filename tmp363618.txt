Cau 2: Tap tin /etc/shadow chua thong tin gi cua users he thong?
Dap an:
Chua thong tin bao mat ve mat khau cua nguoi dung, bao gom:
- Ten nguoi dung.
- Mat khau da duoc ma hoa (hash).
- Ngay thay doi mat khau lan cuoi.
- So ngay toi thieu va toi da giua cac lan thay doi mat khau.
- Thoi gian canh bao truoc khi mat khau het han.
- Thoi gian tai khoan bi vo hieu hoa sau khi het han mat khau.

Cau 3: Tao script thuc hien cac yeu cau quan ly user (U1, U2).
Yeu cau: Tao U1, U2 mat khau sv123456; xem thong tin; tao thu muc KMA_U1 trong U1 roi chuyen sang U2.
Dap an (Script):
#!/bin/bash
# Tao user U1, U2 va thu muc home
useradd -m -d /home/U1 U1
useradd -m -d /home/U2 U2
# Dat mat khau
echo "U1:sv123456" | chpasswd
echo "U2:sv123456" | chpasswd
# Xem thong tin
cat /etc/passwd | grep U1
cat /etc/passwd | grep U2
# Thao tac voi thu muc (chay duoi quyen U1 hoac root)
mkdir -p /home/U1/KMA_U1
mv /home/U1/KMA_U1 /home/U2/
ls /home/U2

Cau 4: Quan ly o dia va sao luu.
Yeu cau: Dinh dang ext4 cho 1 phan vung; mount vao /THI1_HK; rsync file; umount.
Dap an (Script):
#!/bin/bash
# Dinh dang phan vung (vi du /dev/sda2) la ext4
mkfs -t ext4 /dev/sda2
echo "Doi dinh dang thanh cong!"
# Tao thu muc mount point
mkdir -p /THI1_HK
mkdir -p /THI2_HK
# Mount
mount /dev/sda2 /THI1_HK
echo "Da mount!"
# Sao luu rsync (vi du thu muc KMA_U1 tu home U2)
rsync -avzh /home/U2/KMA_U1 /THI2_HK
# Copy thuong
cp -r /home/U2 /THI1_HK
# Huy gan ket
umount /THI1_HK
# Kiem tra lai
ls /THI1_HK

Cau 1: Trong cac tieu chi cua to chuc OSI: Free Redistribution co nghia la gi?
Dap an:
Free Redistribution (Tu do phan phoi lai) nghia la:
- Phan mem co the duoc tu do tang hoac ban nhu mot phan cua goi phan mem.
- Giay phep khong duoc yeu cau tien ban quyen hoac khoan phi khac cho viec ban nhu vay.
- Dam bao quyen tu do chia se phan mem cho bat ky ai.

Cau 2: Co it nhat bao nhieu partition can duoc tao ra khi ta cai dat he dieu hanh Linux?
Dap an:
Can toi thieu 3 phan vung:
1. /boot: Chua kernel khoi dong (min 100MB).
2. / (root): Chua he thong tap tin (min 4GB).
3. swap: Phan vung hoan doi (RAM ao). Kich thuoc swap thuong bang RAM (neu RAM < 32GB thi swap = 2*RAM, RAM lon hon thi tuy chinh).

Cau 3: Tao script quan ly user U3, U4 va nhom root.
Yeu cau: Tao U3, U4; gan vao group root; tao folder /KMA2; copy vao home U3; dung U3 xoa /KMA2.
Dap an (Script):
#!/bin/bash
useradd -m -d /home/U3 U3
useradd -m -d /home/U4 U4
echo "U3:u3_123" | chpasswd
echo "U4:u4_456" | chpasswd
# Gan vao nhom root
usermod -G root U3
usermod -G root U4
# Tao va copy thu muc
mkdir /KMA2
cp -r /KMA2 /home/U3/
# Xoa thu muc duoi quyen U3
su U3 -c "rm -rf /home/U3/KMA2"
ls /home/U3

Cau 4: Quan ly o dia, mount readonly.
Yeu cau: Dinh dang ext2; mount vao /THI/THUCHANH; copy file; umount; remount khong cho ghi/xoa.
Dap an (Script):
#!/bin/bash
mkfs -t ext2 /dev/sda3
mkdir -p /THI/THUCHANH
mount /dev/sda3 /THI/THUCHANH
# Copy file bat ky
cp -r /KMA2 /THI/THUCHANH
# Huy mount
umount /THI/THUCHANH
# Mount lai va set quyen chi doc/thuc thi (khong ghi/xoa)
mount /dev/sda3 /THI/THUCHANH
chmod 555 /THI/THUCHANH

Cau 2: Cho biet cac thu muc sau gom nhung file gi: /bin/; /dev/; /home/
Dap an:
- /bin/: Chua cac tap tin thuc thi (lenh) co ban cho nguoi dung (ls, cp, cat...).
- /dev/: Chua cac tap tin thiet bi (device files) dai dien cho phan cung (sda, tty, sr0...).
- /home/: Chua cac thu muc ca nhan cua nguoi dung (noi luu tru du lieu rieng).

Cau 3: Script mount CDROM va copy file.
Dap an (Script):
#!/bin/bash
# Xem danh sach o dia
lsblk
# Tao thu muc
mkdir -p /KMA/Security
mkdir -p /THI
# Mount CDROM (thuong la sr0 hoac sr2)
mount /dev/sr0 /KMA/Security
# Copy file
cp /KMA/Security/md5sum.txt /THI/
ls /THI

Cau 4: Cau hinh mang IP tinh.

# Restart dich vu mang
systemctl restart NetworkManager

ifconfig ens33

# Tai file (dung wget)
wget download.net/file1

DE SO 4
==================================================

Cau 1: Trinh bay dinh nghia: OSS, Freeware, Shareware, Charityware.
Dap an:
- OSS (Open Source Software): Phan mem ma nguon mo, cho phep truy cap, sua doi ma nguon mien phi (vi du: Linux).
- Freeware: Phan mem mien phi su dung nhung thuong khong cong khai ma nguon (vi du: Chrome).
- Shareware: Phan mem dung thu, phai tra phi de dung ban day du hoac tiep tuc dung sau thoi gian thu (vi du: WinRAR).
- Charityware: Phan mem mien phi nhung khuyen khich nguoi dung quyen gop tu thien (vi du: Vim).

Cau 2: Cho biet cac thu muc sau gom nhung file gi: /sbin/; /tmp/; /var/
Dap an:
- /sbin/: Chua cac lenh thuc thi danh cho quan tri vien he thong (reboot, fdisk...).
- /tmp/: Chua cac tap tin tam thoi, thuong bi xoa khi khoi dong lai.
- /var/: Chua cac du lieu bien doi nhu log files, mail, database (/var/log, /var/www...).

Cau 3: Tao user, file text va phan biet chu hoa thuong.
Dap an (Script):
#!/bin/bash

# Tao file F1.txt va f1.txt (Linux phan biet chu hoa thuong)
touch /home/U1/F1.txt
touch /home/U1/f1.txt
ls -l /home/U1/

Cau 4: Phan quyen va doi ten file voi user khac.
Dap an (Script):

# Doi ten file duoi quyen U25

Cau 1: So sanh GPL va BSD.
Dap an:
- GPL (Copyleft): Yeu cau cac phan mem phai sinh (sua doi tu ma nguon goc) cung phai phat hanh duoi giay phep GPL (ma nguon mo). Bao ve quyen tu do chia se.
- BSD: Cho phep su dung, sua doi va phan phoi lai (ke ca dong ma nguon thanh phan mem thuong mai) ma khong bat buoc phai mo ma nguon cua ban phai sinh. Tu do hon cho nha phat trien thuong mai.

Cau 2: Y nghia lenh locate va find.
Dap an:
- locate "*.xls": Tim tat ca cac file co duoi .xls tren he thong (dua tren co so du lieu da index).
- locate "/usr/oss/*linux*": Tim cac file co duong dan chua /usr/oss/ va ten chua tu "linux".
- find -name "*.pdf": Tim cac file co duoi .pdf trong thu muc hien tai.

Cau 3: Script tao user, group, kiem tra ID.
Dap an (Script):
#!/bin/bash
useradd -m user1
echo "user1:sv123456" | chpasswd
groupadd group1
usermod -G group1 user1
# Kiem tra ID
id user1
# Tao file
touch /home/user1/file1.txt
echo "Hello World" > /home/user1/file1.txt
ls -l /home/user1/file1.txt
